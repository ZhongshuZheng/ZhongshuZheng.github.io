# [经验]树模型特征工程

*创建时间：2021-10-22*

*更新时间：2026-09-12*

## 1. 设计 Benchmark

选取一些最简单、最直观的特征列作为基础 Benchmark，在此基础上进行模型效果分析与迭代。

例如：选取最近一个时间片的特征作为 Benchmark 特征。

## 2. 数据探索

分别对训练集和测试集中的每一项特征进行分析，包括分布、异常值和离群点。

例如：某个格子是新出现的，还是已经失去特征；某个特征是后来才出现，还是后来消失。

## 3. 特征工程

挖掘并利用更多特征内容：

- **时序、空间特征**。
- **统计特征**：如均值、方差。
- **一阶差分**：也可以不做。
- **特征组合**：对特征进行有意义的相乘或相除，例如发单率增长率、司机增长率。
- **业务特征**：需要结合具体业务分析，分桶通常比较好用。例如：
    - 不同数据在相同时刻的发单量均值。
    - 相同格子在不同时刻的发单量均值。
    - 接单率、取消率。
    - 相邻格子的同时间片特征。
    - 主动构建“热门地区分桶”等人工先验特征。
- **纵向组合**：很多不同数据之间的特征可能存在联系，可以进行纵向组合。
- **稀疏与稠密特征处理**：稀疏特征做 Hash；稠密特征做归一化、Log 变换和分桶，以降低噪声与复杂度。

同时可以进行特征相关性分析，并做相应处理：

- **特征衰减**：降低不太相关特征的权重。
- **样本增强**：包括训练集划分调整与正负样本增强。
- **特征泄露检查**：删除在训练集与测试集上相关性差异很大的特征，避免过拟合。
- **正则化或归一化**：对齐表征。

## 4. 调参与正则化

为减小过拟合，需要结合经验和网格搜索进行调参。可以使用交叉验证，也可以选取时间序列中更接近测试集的部分作为验证集。

XGBoost 常用参数：

- `n_estimators`：弱分类器（树）的个数。
- `max_depth`：树的最大深度。
- `min_child_weight`：子节点中样本二阶梯度（Hessian）之和的下限。值较大时，能避免模型学习局部的特殊样本，从而抑制过拟合。
- `gamma`：节点分裂所需的最小损失函数下降值。值越大，算法越保守。
- `subsample`：随机采样训练样本行的比例。减小该值会使算法更保守，但设置得过小可能导致欠拟合。
- `colsample_bytree`：每棵树随机采样的特征列比例。
- `reg_alpha` / `reg_lambda`：L1 / L2 正则化参数。
- Early Stopping：例如将早停轮数设置为 50。

## 5. 误差分析

对验证集结果进行误差分析，查看错误率较高的数据具有什么特点，以便进行针对性分析，例如继续做特征工程或设计相应的损失函数。

例如：热力图中发单量低于 10 的区域错误率较高。

## 6. 损失函数设计

- 考虑与题目评价指标相近的损失函数，可能对刷榜有帮助。
- 考虑多种损失函数，以取得更好的综合效果。

例如使用 MSE、MAE、Huber Loss 或 Fair Loss。
